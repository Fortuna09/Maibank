2. Monte o atalho no iPhone

  1. Abra o app Atalhos e toque em +.
  2. Toque no nome lá em cima e chame o atalho de Anotar gasto — é o que você vai falar para a Siri. Evite nomes curtos que parecem outra palavra: “Mai”, por exemplo, a Siri entende como “mãe” e liga para ela.
  3. Pedir Entrada: tipo Número, pergunta “Quanto?”. Toque na setinha › e ligue Permitir Decimais. Como é um campo de número, a Siri não tem como perder a vírgula: fale “cinco vírgula oitenta”.
  4. Definir Variável com o nome valor (ela pega a resposta de cima sozinha).
  5. Pedir Entrada: tipo Texto, pergunta “Com o quê?”.
  6. Definir Variável com o nome descricao.
  7. Obter Conteúdo do URL, preenchido assim:
    URL
    {{ endpoint }}
    Método
    POST (toque na setinha › para ver)
    Cabeçalho
    Authorization com o valor Bearer + a sua chave (a palavra Bearer, um espaço e a chave, tudo junto)
    Corpo
    JSON com dois campos: valor = variável valor e texto = variável descricao (as duas precisam aparecer azuis; vermelho quer dizer variável quebrada)

    O Atalhos costuma colocar sozinho uma variável no lugar do URL. Se "Obter conteúdo de" não mostrar o endereço, toque ali, apague e cole o endereço acima.

  8. Obter Valor do Dicionário com a chave mensagem.
  9. Falar Texto com o Valor do Dicionário.

Pronto: “E aí Siri, Anotar gasto” → “Quanto?” “cinco vírgula oitenta” → “Com o quê?” “bala” → “Anotado: R$ 5,80 em Bala…”. Rode uma vez pelo ▶ do app Atalhos antes de testar com a Siri.

Prefere falar tudo de uma vez?

Dá para usar uma pergunta só (“Qual foi o gasto?”, tipo Texto) e mandar no corpo apenas texto. É mais rápido, mas a Siri às vezes arredonda os centavos. Se usar assim, fale “vírgula”: “cinco vírgula oitenta de bala”.
